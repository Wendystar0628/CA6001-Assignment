\section{Discussion and Insights}

\textbf{What worked.} The pipeline is auditable: hidden labels never reach the controller, every stop is
audited, and failures are reported. The stop rule vetoed every stop at the one site where stopping would
have failed.
\textbf{What the results reveal.}
\begin{enumerate}
\item \emph{Site predictability decided the savings, more than the algorithm did.} Savings appeared only
  where five CPTs already describe the ground.
\item \emph{Location choice added nothing measurable.} Staged investigation plus a stop rule produced the
  benefit.
\item \emph{Models matter through their decisions.} Profile errors lie within 3\%, but low-cell behaviour
  differs sharply (GP cautious, graph sensitive, CNP blind), which changes what a stop rule can safely
  conclude.
\item \emph{Time dominates the economics.} Decisions must return within the working day, and unpredictable
  sites should revert to the full plan early.
\end{enumerate}

\textbf{Threats to validity.}
\begin{itemize}
\item The development sites were checkpoint-selection sites during source training. This likely explains
  why learned models beat the GP by 12\% there but by 1\% on evaluation sites, and it means the model
  ranking is within noise.
\item The evaluation sites had been inspected in an earlier project stage, so this is a re-evaluation, not a
  blind test.
\item With 4 sites, 5--16 audit positions per site and 7 early stops, the 95\% upper bound on the
  false-stop rate is about 40\%.
\item New Lock is the only non-New-Zealand site and the largest, so domain shift and heterogeneity are
  confounded there.
\item The economics rest on assumed values and on $\alpha=1$.
\end{itemize}

\textbf{Future improvements.} Quality-predictive stop signals would take the clear opportunities at
Christchurch Stadium and Hollywood. A site-predictability check after the initial CPTs would catch New
Lock-like sites early. Same-day decisions would remove most of the delay cost. An event-weighted loss on a
0.1\,m grid would help low cells. Finally, the method should be tested on genuinely new sites with real
cost data.
