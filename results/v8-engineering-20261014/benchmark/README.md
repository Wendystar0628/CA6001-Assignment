# v0.8 串行工程性能基准

> 本目录保留未固定 CPU 核的诊断数据。后续发现同一 IDW 在不同轮次出现约 2 倍耗时差，因此最终报告改用 [同一进程、固定 logical core 2 的统一基准](../benchmark_pinned/README.md)。下表不再作为最终速度结论，也不与其他批次交叉计算加速比。

2026-10-14。全部训练、质量实验和测试停止后执行。17 个实现条目，共 612 次计时调用；每条目使用相同 12 状态，每状态先预热 1 次，再测 3 次。每次均重新 `condition`，再真实 `predict`，没有把最终预测缓存当作推理。

硬件为 Intel Core i7-14700KF、RTX 4080（驱动 610.88）。CPU 数值库限制 1 线程；CUDA 在计时边界同步。状态为 3 折 × 各 2 验证场地 × seed 17 × 预算 5/13。仅 4 个不同场地，跨折重复不代表独立场地。

## 完整点预测和完整风险流水线

下表为每次 `condition + predict` 的毫秒数。总体中位数/p95 来自每条目的 36 次计时；加速比是先对每状态 3 次取中位，再计算旧/新比值，最后对 12 个状态取中位，因此不必等于表中两个总体中位数相除。

| 完整推理范围 | 原实现中位 / p95 ms | 优化实现中位 / p95 ms | 配对加速比 |
|---|---:|---:|---:|
| 结构组合点预测（支持集 LOO stack + simplex） | 866.19 / 1264.80 | 49.26 / 72.38 | 16.51× |
| Haar 厚度点预测（不含独立风险头） | 76.25 / 87.93 | 20.93 / 22.40 | 3.72× |
| 训练后 TabPFN guarded 残差点预测，真实 CUDA | 941.39 / 1496.99 | 153.49 / 260.52 | 5.37× |
| 均衡系统完整点预测（结构组合 + 联合厚度决策） | 1219.87 / 1728.73 | 72.93 / 93.65 | 16.67× |
| 均衡系统完整点预测 + 原生经验风险头 | 2449.55 / 3684.30 | 317.62 / 338.63 | 7.90× |

完整均衡系统风险头实际重新计算 TabPFN 残差、图 Huber、其组合与支持集误差 CDF。没有读入缓存风险概率。外部验证使用的 Platt 校准拟合及 I/O 不属于本次推理范围。

## 保留的基线实现

| 基线 | 中位 ms | p95 ms |
|---|---:|---:|
| 当前支持集常数中位数 | 3.89 | 4.56 |
| 原 IDW 完整点预测 | 109.32 | 140.98 |
| 原 GP 重新拟合 + 原生分布预测 | 123.47 | 524.13 |

GP 使用各折原源训练深度趋势与原配置，不为速度改参数。Marshland 个别状态产生原长度尺度上界警告；本次没有因此重调强基线。这里反映当前实现的成本，不能把原 IDW 的逐行 pandas 开销解释为 IDW 算法本身低效。另行等价优化 IDW 对照应独立列出。

## 等价与内存解释

- 7 对旧/新实现的所有计时状态均通过输出数值等价检查；原始逐状态结果在 `paired_output_checks.csv`。
- 均衡完整流水线的原生风险概率与既有 `v6_empirical_graph_union_local` 参考最大绝对差为 **8.88e-16**，阈值 0.2 下标签变化为 **0**。参考只在真实推理结束后用于核对，未传给预测器。
- CUDA peak allocated 中位约 **125.54 MiB**，最大 **197.00 MiB**；新旧相同模型权重，没有测出显存容量下降。这不包括 CUDA 驱动、allocator reserved 等全部进程显存。
- `rss_after_mib` 是整个 Python 进程推理后工作集绝对值，包含库导入、此前模型和缓存的影响。它不是模型独占内存，也不是模型峰值，不能用于内存节省排名。
- 初始化按 factory/fold 单列：构造、显式权重加载分别记录。第一次旧 TabPFN 初始化约 3.281 s，后续折约 69–77 ms；优化路径约 68–135 ms。首次懒加载和缓存状态不同，只有每折 1 次，不能据此声称冷启动加速比。
- 36 次异质状态计时中的 p95 仅用于描述；12 个状态不足以证明稳定服务尾延迟。阶段中位数也不必加和等于完整时延中位数。

## 复现与数据

```powershell
.venv/Scripts/python.exe -m cpt_budget.v8.benchmark --registry cpt_budget.v8.runtime:benchmark_specs
```

执行前停止其他模型计算。`samples.csv` 保存逐次计时和原始阶段计时，`state_summary.csv` 保存逐态中位，`paired_state_ratios.csv` 与 `paired_summary.csv` 保存配对比值；`initializations.csv`、`initialization_summary.csv` 单列初始化；`stage_summary.csv` 保存完整流水线各阶段描述统计。硬件、包版本、来源提交和完整范围定义在 `protocol.json`。
