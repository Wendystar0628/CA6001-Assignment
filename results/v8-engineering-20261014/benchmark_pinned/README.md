# v0.8 正式工程基准：同进程、固定逻辑 CPU 核

2026-10-14。正式报告采用本目录的统一批次。26 个条目在一个新进程中串行完成，CPU 亲和性固定为 **logical core 2**，Windows 允许掩码为 `0xfffffff`，设置并回读为 `0x4`。不根据编号推断它属于 P 核或 E 核。数值库仍限制 1 线程，CUDA 在计时边界同步。

之所以重测，是此前未固定核时，同一原 IDW 出现约 2 倍跨轮耗时差。统一批次在开头和结尾再次运行同一原 IDW，中位时延分别为 **56.105 / 56.557 ms，相差 0.80%**；逐状态前后差异范围为 **−0.41% 至 +2.76%**，明显缓解了观察到的波动。CPU/GPU 频率没有锁定，条目顺序没有随机化，因此仍保留顺序和系统调度造成的小幅变化可能性。旧 `benchmark`、`benchmark_families`、`benchmark_baselines` 仅作诊断，不跨批次计算最终加速比。

## 测量范围

- 硬件：Intel Core i7-14700KF、NVIDIA RTX 4080；驱动 610.88。
- 状态：3 折 × 各 2 验证场地 × seed 17 × CPT 预算 5/13，共 **12 状态**，只有 4 个不同场地。
- 每条目每状态先预热 1 次，再测 3 次；每次都重新 `condition` 并真实 `predict`。共 **936 次计时、312 次预热、78 次 factory/fold 初始化**。
- 表中 `中位 / p95` 来自该条目 36 次 `condition + predict` 的毫秒值。每状态先取 3 次中位，再计算旧/新比，最后取 12 状态比值的中位作为配对加速比；它不必等于两个总体中位数相除。
- 初始化、权重加载、数据读取、输入副本、评价与校准不计入热态推理。初始化独立测量，CUDA 同步包括在计时边界内。
- 对于“完整点 + 原生经验风险”，真实重新运行 TabPFN 残差、图 Huber 组合及支持集误差 CDF；没有读入最终点预测或风险概率缓存。外部验证的 Platt 校准拟合不属于推理。

| GP 拟合 + 原生分布预测 | 73.48 / 198.37 | — | — |

公平 IDW 优化保持原始标量 `idw_value` 和所有数值参数，只复用剖面与几何。优化后 IDW 比上述复杂点模型更快，因此不能再利用原 IDW 的逐行 pandas 成本证明复杂模型更高效。质量收益应与这份真实速度代价一起报告。

GP 使用原源训练趋势与原配置，没有为速度减少优化步骤；个别 Marshland 状态仍触及既有长度尺度上界，未因此重调基线。

## 等价、初始化与内存

**10 对旧/新实现的计时状态全部数值等价。** 9 个完整系统/质量变体的原生风险概率均对照既有 `v6_empirical_graph_union_local`，最大绝对差为 **8.88e-16**，0.2 阈值下标签变化为 **0**。参考仅用于推理结束后的评价，从未提供给预测器。

初始化按 factory/fold 独立记录。TabPFN 旧路径 3 次初始化中位 **37.87 ms**，范围 **37.45–1125.43 ms**；新路径中位 **39.37 ms**，范围 **36.34–39.49 ms**。第一次模型初始化包含懒加载，没有足够独立冷启动重复，不能声称权重初始化获得倍数加速。均衡完整流水线初始化中位约 39.5–39.7 ms。

GPU 条目的 CUDA peak allocated 中位约 **125.54 MiB**，全批次最大 **197.00 MiB**。相同权重的新旧路径没有观察到峰值显存降低；该值不包含全部驱动和 allocator reserved 显存。`rss_after_mib` 是整个 Python 进程工作集绝对值，受此前导入和模型影响，不能当成某个模型独占内存或内存节省证据。

每条目只有 36 次异质状态样本、12 个状态，p95 只是描述量，不能直接作为上线服务的稳定尾延迟承诺。

## 复现

执行前停止其他模型计算，然后：

```powershell
.venv/Scripts/python.exe -m cpt_budget.v8.benchmark --cpu-core 2 --registry cpt_budget.v8.runtime:benchmark_specs --registry cpt_budget.v8.runtime:family_benchmark_specs --registry cpt_budget.v8.baselines:benchmark_specs --output runs/v8-engineering-20261014/benchmark_pinned
```

`protocol.json` 保存实际亲和性掩码、完整条目顺序、硬件、软件版本和作用范围；`summary.csv`、`paired_summary.csv` 给出总表，`samples.csv` 与 `paired_state_ratios.csv` 可逐状态复查。`idw_timing_stability.csv` 记录前后同一 IDW 的逐状态差异。`initializations.csv` 与 `initialization_summary.csv` 单列初始化。旧/新数值对照与旧风险来源对照分别在 `paired_output_checks.csv` 和 `native_reference_checks.csv`。
