# 整曲线误差分布：v8 工程优化与支持集适配

本轮完成了主均衡方案中整曲线决策算子的实质优化：将每个深度点的 Pandas 邻域重建，改为 condition 阶段一次提取完整剖面、构造整组排除的 LOO 几何算子，再批量生成所有查询位置的整曲线原子、概率、计数与稳定排序决策。统计规则未变，所有候选使用同一个结构幅度底座 `v7_simplex_structural_s050_gp`。

## 等价性与计算范围

- 全部 60 状态、8,640 单元验证：Fast 与 Reference 的点预测最大绝对差为 **0**；native 概率最大差为 **2.22e-16**；所有整曲线中位计数相同。
- 新的等价点预测与冻结的 `v7_frontier_structural_error_joint` 存档逐单元完全相同。
- 5 项定向测试通过，包括整组/共坐标排除、任意查询行序、稳定概率/幅度/深度排序、支持集适配计数一致性。
- 初轮组件计时在并发实验环境中进行，缓存的幅度输入不计入算子时间。因此 `component_benchmark.csv` **不是整套方案的端到端速度**，正式运行速度以父任务串行基准为准。
- 初轮条件构造中位数由 232.9 ms 降至 8.40 ms，查询预测由 22.0 ms 降至 5.92 ms。改进来自消除重复逐行邻域构建与批量处理，不依赖预测缓存替代算子。

提供 `old_factory(fold_id)` 与 `new_factory(fold_id)`，实际执行优化前/后的结构模型，再执行整曲线决策，可用于端到端基准。单完整状态真实链路检查点差 4.44e-16、概率差 1.11e-16。这条链路使用**原生 joint 风险头**；历史 empirical 风险头另有独立 Graph/TabPFN 路径，不能把它的耗时纳入或省略后混称相同完整系统。

## 质量适配结果

以下为预算曲线 AUBC，先平均种子与折，再按 4 个不同场地等权平均；风险校准由父任务统一执行。所有参数选择只访问当前已测支持集，质量候选在运行前记录于 `method_protocol.json`。

| 候选 | log-MAE | 厚度 MAE (m) | 点召回 | 点误报 |
|---|---:|---:|---:|---:|
| 等价 fast 主线 | 0.592435 | **0.536947** | 0.385239 | 0.083080 |
| 支持集选择误差收缩 | 0.593583 | 0.549479 | 0.395000 | 0.085955 |
| 支持集选择计数收缩 | **0.591791** | 0.546712 | 0.382011 | **0.079833** |
| 支持集校正有符号计数偏差 | 0.592953 | 0.568197 | **0.405525** | 0.089695 |

1. **误差收缩**：在支持集整组 LOO 上，用厚度绝对误差从 0.25/0.5/0.75 选择误差原子的收缩程度。厚度总体变差，不作为替代主线。
2. **计数收缩**：用整组 LOO 从 0/0.5/1 选择联合计数与底座计数的混合权重。连续误差与误报略降，厚度稍差；Marshland 点召回由 5.15% 升至 6.62%，仍未充分解决漏识别。
3. **有符号计数偏差**：估计支持集整组 LOO 的计数残差中位数，每个近邻组等权，限制修正为 ±2 格（±0.5 m）。平均召回提高约 2.03 个百分点，但厚度与误报恶化；改善主要集中于 Metro Sports，未形成跨场地的稳定收益。

这三种适配中的 LOO 幅度预测均使用 3NN IDW 代理，**不是完整结构模型自身的严格交叉验证残差**。未测目标标签不参与适配，但代理误差向当前强模型迁移仍可能失真。计数收缩/偏差改动的是最终点标签，native 边际概率没有因此变成新点决策的同一分布。这些边界会保留在统一报告中。

## 推荐

将等价 fast 算子作为工程替代，保持主线厚度表现；计数收缩和偏差校正只保留为有明确代价的备选，不能宣称三项优化都提升了质量。后续应重点改进结构模型自己的支持集误差迁移，避免用粗糙代理校正已经较好的基底。

复现：`.venv/Scripts/python.exe -m cpt_budget.v8.joint`。完整点表、分场地结果、支持集适配参数和组件计时位于本目录；所有比较仍属于反复使用的验证集探索，没有新的独立测试确认。
