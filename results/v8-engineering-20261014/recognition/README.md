# 识别优先方案的工程优化与质量取舍

本组以 `v7_pair_joint_recognition_empirical_graph` 为参照：点预测使用 `support_stack_structural` 振幅基底、整根 analog 曲线分布及厚度中位数决策；风险预测保留独立的 `v6_empirical_graph_union_local` 概率头。所有变体均使用同一个风险头，因此本组主要研究真实点标签 `pred_log_qc < 0` 的变化，不将风险阈值结果冒充点召回。

## 实现与参数

1. **精确快路径**：共享 `v8.joint.FastJointAdapter`，条件化时一次计算支持集矩阵与整组 LOO 几何算子，批量计算全部 query 曲线原子、事件概率与厚度中位数，替代逐深度 pandas 查询和逐曲线分布处理。
2. **localize**：保留原 count median。将 analog 边缘事件概率与已测剖面深度 ±1 格的经验事件率融合，融合量由支持集整 near-group LOO 的 Brier skill 决定，最高 0.35；无正技能时为零。深度核固定 `[0.25, 0.5, 0.25]`，端点归一化。调整固定低阻力格数的空间位置，不改变厚度格数。
3. **amplitude**：在 localize 基础上，仅对发生跨阈值修改的格子，将原 ±0.05 和同深度邻域已测同类别 logqc 加权中位数各取一半。保留选中的类别与厚度格数，检验跨阈值幅度能否恢复。
4. **recall60**：保留同一曲线原子与 localize 定位，厚度格数取原联合分布的 60% 分位数。它明确提高漏检代价，不是改变评价阈值或重新命名厚度。

三个质量变体及数值参数在本组评分前发给主代理固定；不使用 query 真值、场地 ID 特判或评价风险校准标签来生成点预测。全部方法覆盖同样 60 个状态、每方法 8640 行。

## 点性能

下表沿用预算曲线面积、先场地内折平均再 4 个独立场地等权的统一口径。H 是从最终点预测阈值事件计算的真实厚度绝对误差。

| 方案 | log-MAE ↓ | H MAE (m) ↓ | 点召回 ↑ | 点误报 ↓ |
|---|---:|---:|---:|---:|
| IDW | 0.638586 | 0.630371 | 37.3767% | 7.2766% |
| GP | 0.650156 | 0.667155 | 33.4348% | 7.3745% |
| v0.4 TabPFN 残差 guarded a050 | 0.620528 | 0.630371 | 37.3767% | 7.2766% |
| v0.7 识别优先 / v0.8 精确快路径 | 0.612355 | 0.547363 | 41.8877% | 7.8527% |
| **localize** | **0.612305** | 0.547363 | 42.3760% | **7.8102%** |
| amplitude | 0.616248 | 0.547363 | 42.3760% | 7.8102% |
| **recall60** | 0.613079 | **0.526855** | **48.7655%** | 9.1364% |

`localize` 对原识别模型产生小幅同向改善：召回 +0.4883 个百分点、误报 -0.0425 个百分点，厚度完全不变。它的收益很小，不能包装成明显突破。

`amplitude` 在保持相同分类决策时增加了连续误差，说明邻近已测的同类振幅不能直接视为查询位置的合适振幅。保留此负结果，不推荐替换 localize。

`recall60` 相对原识别模型召回 +6.8778 个百分点、误报 +1.2837 个百分点，平均 H 误差下降约 3.75%。这是可用的识别取舍，适合漏检代价较高的方向，不能宣称所有指标均改善。

## Marshland 与场地边界

| 场地 / 方案 | H MAE (m) ↓ | 点召回 ↑ | 点误报 ↓ |
|---|---:|---:|---:|
| Marshland 原识别 | 0.492188 | 19.5588% | 2.5977% |
| Marshland recall60 | **0.457031** | **30.0000%** | 3.1202% |

localize 在 Marshland 平均融合权重只有 0.000922，未改变它的点召回：当前支持集的空间事件 LOO 技能不足，算法拒绝强行相信邻域事件率。recall60 在四个场地均提高召回，同时四个场地误报均提高。厚度仅在 Marshland、Tauranga 改善；Lower Hutt 从 0.302083 增至 0.367188 m，Metro Sports 从 0.412109 增至 0.427734 m。

各质量变体的 native 风险头与原识别模型完全一致，原共同校准结果为风险召回 68.2143%、风险误报 23.9039%；总报告由统一评价器复算确认。本组的 localizer 分数只是定位辅助量，不作为校准风险概率或联合分布概率输出。

## 工程结果与复现

`equivalence.json` 记录精确快路径与 v0.7 识别方案在全部 8640 行上最大点值差 **0**、标签差 **0**、native 风险概率差 **0**。`ReferenceRecognition` 与 `FastRecognition(variant=...)` 均提供 `condition(observed)`、`predict(query, base_values)` 实时算子，可接受完整管线当场生成的振幅基底；类本身不从磁盘读取最终预测。

`component_timings.csv` 记录真实支持集条件化和点决策的耗时：并行运行时每状态中位数分别约 14.25 ms（exact）、20.47 ms（localize）、20.82 ms（amplitude）、20.45 ms（recall60）。**这些数字不包含振幅基底和独立风险头推理，不是整套模型耗时**；最终横向速度比较应使用总报告的统一实测基准。

定向检查 `tests/test_v8_recognition.py` 共 4 项通过，覆盖批量与旧实现等价、打乱 query 行后恢复顺序、整 near-group LOO 排除、幅度投影保持标签和真实厚度、query 真值拒绝。

```powershell
.venv/Scripts/python.exe -m cpt_budget.v8.recognition
.venv/Scripts/python.exe -m pytest tests/test_v8_recognition.py -q
```

本结果来自反复使用的探索验证集，没有新增独立测试确认。质量改动不能借助快路径的精确等价结论取得额外有效性保证。
