## 结构机制与边界

`P = components.T @ components` 是对应 fold 源训练 FPCA 子空间的正交投影，实际每折 8 维。投影候选满足 `prediction P = F P`，并且 `prediction(I−P)=R(I−P)`。它将 FPCA 支持的共同变化交给 F，保留 R 在正交补中的细节；这与普通凸混合同时缩小两部分不同。

FPCA 子空间不是物理频率滤波器，所以“正交补细节”不能直接等同于真实薄层，也不能据此宣称低阻力事件一定保留。该候选实测厚度优于 R 的 0.630371 m，但原点召回仍低于 R 的 0.373767。

50% 凸混合连续误差最低，然而原点召回下降。保护候选改善连续误差且保留原点厚度与分类，其设计上不能改善 R 的低阻力标签；它也不能保证外部校准后的风险标签保持不变。三方简单平均没有自动取得三种结构各自的优势。

源 FPCA 的局限仍存在：以源场地内协方差捕捉全剖面形状，低秩均方意义上的主变化可能压低小幅、少见的薄弱层信息。若继续研究，值得把厚度/事件预测与连续均值重建明确分开，使用仅由已测 CPT 或源训练拟合的剖面事件模型；不应按查询真值调一个全局平移量来制造召回提升。
