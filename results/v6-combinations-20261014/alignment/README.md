# 配准形状与最佳残差的冻结组合

目的：检验 v0.5 配准剖面在厚度上的优势，能否与 v0.4 最佳残差方案的连续值优势互补。输入仅为 `residual_ft_crps_guarded_a050` 和 `registered_profile_shape` 的冻结点预测；候选生成器拿不到 query truth、风险标签或既有校准分数。

六个构造在实验前通过代理协作消息冻结；不是独立预注册研究，沿用已有验证场地。完整输出每模型 60 状态、8,640 深度格，共 360 根 query 剖面实例。主代理统一进行风险校准与综合门槛判定。

令 R 为最佳残差预测，S 为配准形状预测；每根剖面均为 24 个深度格。

| 模型 | 构造 | 要检验的机制与代价 |
|---|---|---|
| `v6_shape_blend025` | 0.75 R + 0.25 S | 小幅引入配准形态 |
| `v6_shape_blend050` | 0.50 R + 0.50 S | 等权互补 |
| `v6_shape_blend075` | 0.25 R + 0.75 S | 以配准厚度优势为主 |
| `v6_shape_residual_amplitude` | mean(R) + clip(std(R)/std(S), 0.5, 2) × (S − mean(S)) | 由残差给出均值和振幅尺度，由配准决定异常的深度位置；尺度剪裁会限制精确方差匹配 |
| `v6_shape_residual_trend` | smooth5(R) + S − smooth5(S) | 残差提供缓变趋势，配准提供局部凹陷；若凹陷为噪声，也会扩大误报 |
| `v6_shape_residual_softmin` | −0.25 log[(exp(−R/0.25)+exp(−S/0.25))/2] | 在两者低值与均值之间偏向低阻力，敏感度收益须与误报一并评估 |

`smooth5` 使用五格等权滑动平均（1.25 m 窗口），端点采用 NumPy `reflect`，不重复端点。振幅构造仅为数值防零使用标准差下限 1e−12。softmin 使用稳定的 logsumexp，两个预测相等时严格保持该值，不人为下调所有预测。

这属于锥尖阻力曲线的形态与幅度组合；这里的“事件位置”指模型预测的低阻力凹陷，**不表示已识别真实地层或人为生成地质标签**。也不能恢复 0.25 m 网格无法分辨的薄层。所有输出为点值，旧成员的分位数、风险概率与校准结果均被丢弃，避免把混合结果错误包装成原有分布模型。

关键检查：4 项通过，覆盖成员相同时保持原预测、振幅转移保留配准深度排序、softmin 数值边界/对称性，以及输入无效时停止。未重新训练成员，也未依据本轮指标改变任何混合权重。

复现：`.venv/Scripts/python.exe -m cpt_budget.v6.alignment_combinations`。
