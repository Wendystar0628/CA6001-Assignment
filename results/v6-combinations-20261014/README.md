完成日期：2026-10-14。五个子代理并行推进，主代理统一口径、评分和主线提交。完成 **58 个新候选组合**，每个完整运行60个冻结状态；连同32个既有参照，总计90模型、5,400条预算指标。没有重新训练TabPFN，没有替换IDW／GP强基线。

**原综合门槛已通过。按用户最新的连续误差改善3%目标，第三轮保留的跨折选择系统同时达到误差改善4.04%、厚度改善10.09%。** 这是探索验证结果；单个固定模型尚未同时达到这组额外目标，也尚无独立测试确认。

## 四轮实际探索了什么

1. **18个结构组合**：图／FPCA／形状配准与最佳残差的固定权重混合、符号保护、低值并集、源子空间投影、形状幅度分解及图LOO偏差延拓。改善数值的混合往往抹平低值；纯符号保护无法改善原点厚度。
2. **8个事件与自适应方法**：低值指示概率、垂向Potts、软计数约束、精确MAP/边缘概率；支持集整根LOO选择空间成员权重。约束直接作用于实际log(qc)符号，H_point没有换成期望厚度。
3. **23个概率、事件耦合与源双头组合**：已测条件误差CDF，独立GP风险头，结构点基座接事件解码，源训练厚度和事件ExtraTrees。源双头共1,536棵树，实际单线程训练152.58秒，特征构建另约79.3秒。训练情景有重复：三折1,600／1,576／1,688条profile-episode，去重查询CPT为200／190／210根，不能当作数千独立剖面。
4. **9个互补与计数投影**：不同错误来源的等权组合／逐格中位数，加GP事件解码；保留学习到的同一低值格数，按点值排序重新放置低值单元。后者在不改变每根预测厚度的情况下减少幅度损伤，说明“预测多少低值”和“低值放在哪些深度”值得分开建模。

负结果也保留：源事件树头虽然提高某些点指标，跨组校准risk FPR约59.36%，没有通过；图LOO偏差延拓损伤平均连续误差；直接混合的某些厚度／召回收益不足。没有继续修改这些候选参数以隐藏失败。

## 可信范围与复现

- 仍是3fold、种子17/29、预算5/7/9/11/13的60状态，只有4个不同验证场地。同一场地的重复fold先合并，再等权平均；深度格和反复预算不是独立样本。
- 特征与预测只接触源训练或当前已测CPT；整根LOO排除近邻组和共坐标。冻结缓存输入按白名单读取点预测／原生概率，旧OOF风险及查询真值不参与生成。
- 所有方法共享留勘察组校准；原生概率的构造各不相同。经验误差分布只是IDW误差向其他点基座的近似迁移，没有conformal覆盖保证；独立GP风险头不是组合点预测的完整CDF。
- 原图Huber存在29/60未严格收敛状态；本轮新增LOO偏差图20/60未严格收敛，均保留标记。没有为追分修改迭代上限。
- **多轮搜索、模型选择和成绩共享验证集，有选择乐观偏差。没有独立outer-test，没有统计显著性或补勘根数节约证明。** 当前推荐可供冻结后进一步确认，不能直接作为已验证部署收益。
- 34项定向检查通过，覆盖真值边界、完整剖面、精确二元推断、计数一致性等。另一代理从最终curves独立复算了推荐系统、4场地权重、58候选完整性及门槛，数值一致。

设计来源和参数详见[实验协议](../../docs/V6_COMBINATION_PROTOCOL.md)及各family目录。新方法参考包括[指标地统计](https://link.springer.com/article/10.1007/s11004-008-9146-8)、[CPT隐马尔可夫场研究](https://ascelibrary.org/doi/10.1061/(ASCE)GM.1943-5622.0002113)、[概率预测系统及其假设](https://proceedings.mlr.press/v60/vovk17a.html)、[ExtraTrees](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.ExtraTreesRegressor.html)；本项目适配实现不等于这些论文的完整复现。
