## 未定义值的处理

- **Wellington Airport的5个评价集都没有qc<1 MPa的单元**：点召回、风险召回在全部5个种子上无定义（NaN），按v0.9.1聚合（pandas跳过NaN）不参与召回均值，因此召回只来自3个场地（表中`n_sites_recall`＝3）。该场地上所有入口的点厚度MAE都为0、点FPR都为0（没有入口预测出低值），风险FPR接近0。
- Hollywood每个评价集只有1–4个低值单元（共120个单元），召回在少数单元上取值，粒度粗（多数入口为20%）。
- New Lock低值单元很多（每个评价集64–100个，共384个），厚度MAE（1.3–1.7 m）和点FPR主要由它决定。
- GP是唯一有区间的入口，90%覆盖率86.5%。

## 意外之处

1. **常数中位数的厚度MAE（0.4711 m）低于IDW（0.5036 m）**：常数从不预测低值，在Airport（无低值）和Hollywood（极少低值）上厚度误差最小；只有7个入口（thickness、thickness_guarded、simplex、gp、balanced、tabpfn_joint、count_shrink）的厚度MAE低于常数。厚度结论应结合逐场地表阅读。
2. 在New Lock上，常数（1.0166）和CNP（1.0093）的log-MAE低于所有空间模型，IDW为1.1163。
3. **风险校准迁移到New Lock效果差**：用Lower Hutt与Tauranga标签拟合的fold 1校准器，使共享风险头在New Lock的风险FPR达62.7%，常数/CNP的风险标签几乎把New Lock全部标为高风险（85%/100%）。等权风险召回上IDW＋Platt（57.0%）和simplex（68.7%）高于共享经验风险头（46.7%）。
4. tabpfn_graph的厚度在测试上排最后（0.5513 m），主要来自New Lock（1.677 m）。

## 局限

- 只有4个场地，2个分组未核实；评价集每场地5–16个位置，在(场地,种子)内固定，种子之间不是独立重复。
- **协议勘误（揭盲后发现，不影响任何计算）**：协议第7节第1条写“种子间评价集固定”，与数据不符。评价集在每个(场地,种子)内固定，但不同种子抽取的评价集不同：20个(场地,种子)组合共有19个不同的评价集（见`prepare_summary.json`）。协议文件受冻结哈希保护，因此保留原文，在此更正。
- Airport无低值、Hollywood低值极少，召回与厚度对比的信息主要来自Stadium与New Lock。
- 测试场地在其他折中是训练源，这些折的权重参与了验证场地上的选择（弱间接通道）。
- 风险校准每折只用2个验证场地，对新场地的迁移有限（见New Lock）。
- 只评价冻结maximin揭示序列下的预测质量，不评价选点策略，也不证明节省CPT。
