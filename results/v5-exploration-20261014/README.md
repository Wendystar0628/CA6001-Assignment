# v0.5：新算法方向探索与弱基线

完成日期：2026-10-14。五个子任务并行完成文献核实、实现与实验；全部在CPU运行，未继续调优原TabPFN／IDW／GP方案。代码直接提交main，标签`v0.5-exploration`。

**本轮最值得保留的新方向是图Huber重建、FPCA＋空间核岭和形状配准。** 它们分别改善连续剖面误差、部分联合指标和厚度误差，但各有识别或稳定性代价，没有新增候选通过原综合门槛。常数中位数已提供一个明确较弱、透明且合理的参照，其平均误差比IDW高39.24%。

## 研究与实验口径

新增9个候选：两个低信息基线、两个功能型剖面模型、两个图重建模型、两个剖面配准模型、一个条件神经过程。每个均完成相同60个预算状态／8,640个深度行；另保留v0.4全部23个参考，总比较为32模型、1,920个预算指标行。

三折、种子17/29、预算5/7/9/11/13、Maximin支持集和固定评价位置不变；2–8m、24单元、1MPa阈值不变。先预算归一化积分，再平均种子、同一场地重复fold，最后对4个不同验证场地等权。CNP和FPCA只从对应源训练场地学习；不读取outer-test标签选参数。

这些仍是已被多轮使用的验证场地，属于探索性结果。没有新的独立测试，也没有补勘根数节约证明。新方法均为点预测；表中的risk是统一留勘察组校准后的概率决策，不是新方法的原生分布。

## 推荐的新方向及其机制

### 图Huber重建：优先研究全场几何与边界保留

将完整计划位置及深度单元构成图，已测剖面作为边界，联合重建未测信号。调和版本惩罚平方边差；Huber版本降低大跳变受到的惩罚，试图保留边界。它与既有逐深度IDW或连续Matérn GP的结构不同，但并不声称图方法与空间统计完全无关。

Huber的平均误差较IDW降低**2.03%**，3/4不同场地误差改善；校准risk Recall74.12%、FPR27.55%，优于IDW的69.55%／38.35%。不过H_point误差增加约0.0645m，四个场地的厚度误差都变差；平均风险改善还掩盖了Tauranga的FPR增加约12.74个百分点。因此适合作为连续重建与风险取舍方向，不能认定综合优胜。

数值边界：固定40轮IRLS下31/60状态满足严格收敛阈值，29/60未满足；目标函数均下降，最大驻点残差约9.06e-6，已测边界误差0。当前成绩对应这个固定求解预算，不把未收敛记录删掉，也未为提高成绩追加迭代。图获得的是全部计划位置的无标签几何，不包含未测qc。

方法依据：[图调和函数半监督学习](https://mlg.eng.cam.ac.uk/zoubin/ssl.html)、[图总变差学习](https://arxiv.org/abs/1901.09838)。本实现是图信号重建适配，不是原论文完整复现。

### FPCA＋空间核岭：优先研究整根剖面的共同结构

把每根24单元剖面视作一个函数，用源训练场地等权主成分表示共同垂向变化；在目标场地用已测剖面的均值作截距，再预测低维系数并重建整根剖面。主成分基不接触验证或测试标签，目标截距仅来自当前已揭示CPT。

核岭版本较IDW误差降低**0.91%**，厚度误差略降，3/4场地误差改善；但Lower Hutt明显变差，原点Recall下降7.51个百分点。线性系数趋势版本表现较差，不建议作为下一轮优先方向。

固定规则是解释90%源方差但最多8维；三折均达到8维上限，实际仅解释82.81%／83.10%／83.29%。不能写成“保留90%信息”，低秩平滑可能删除薄层变化。

理论参考：[空间相关功能型主成分研究](https://link.springer.com/article/10.1007/s11222-016-9708-4)。这里实现的是离散FPCA＋确定性空间回归，不是该论文SPACE方法复现。

### 单调剖面配准：优先研究厚度与层界错位

先对已测邻近剖面的深度形状做受限单调对齐，再按计划位置插值形状与深度映射，最后变回真实深度。查询位置的真实剖面从不参与对齐。位移固定限制在±0.5m，端点固定，局部厚度比例限制为0.5–1.5。

标准化形状版本的厚度误差从IDW的0.630371m降至**0.595215m，改善5.58%**；连续误差仅改善0.46%，原点Recall及校准误报仍有代价。绝对值版本连续误差改善1.12%，厚度基本相同。

配准参考：[Petitjean的DTW／barycenter研究](https://www.francois-petitjean.com/Research/DBA.php)。当前是受启发的受限单调配准适配，不能把对齐曲线当作真实地层标签。所有查询都产生非零对齐，支持剖面位移经常达到上限；24格粗网格不支持对更薄层作恢复保证，也存在误配风险。

### 条件神经过程：本轮具体实现不值得优先追加投入

实现非Transformer、非残差的query-relative DeepSets：整根剖面编码、相对位置输入、集合mean＋max汇聚、深度条件解码。共26,817参数，三折实际600／500／1200次更新，最佳200／100／800步，共2,300次真实更新。

平均误差比IDW高约33.80%，所有评价状态的点预测都没有识别出低于1MPa的单元。它仅略好于常数弱参照，不能用“神经网络”名称代替效果。本结论针对这个固定的小网络与数据预算，不推广到全部神经过程。

来源：[Conditional Neural Processes](https://proceedings.mlr.press/v80/garnelo18a.html)。本实现为确定性点预测适配，没有原生不确定性，不冒充原论文全部能力。

## 建议采用的弱基线

**主弱参照使用常数中位数模型。** 每轮将全部已测log(qc)的中位数预测给所有查询位置／深度；它是L1意义下的最优常数截距参照，对应标准[DummyRegressor的median策略](https://scikit-learn.org/stable/modules/generated/sklearn.dummy.DummyRegressor.html)。它没有故意错误参数、随机破坏或隐藏标签选择。

- 常数参照0.889189，比IDW误差高**39.24%**；反过来，IDW相对它误差下降**28.18%**，两个百分比的分母不同。
- 深度中位数0.775819，比IDW高**21.49%**，适合作为“保留深度、去掉水平空间关系”的中间参照。
- 常数模型在Tauranga反而比IDW误差低约9.10%，因此不能声称它在每个场地都更差。
- 常数模型原点Recall和FPR同时为0；它没有报出低值，不能拿零误报宣称风险识别好。其表中25%的risk FPR来自另一个校准决策口径。

论文／报告应同时展示“低信息参照→IDW／GP强基线→新方法”。例如v0.4最优模型较常数参照降低约30.21%误差，其中IDW本身已经实现28.18%的下降，不能把全部30.21%归为TabPFN贡献。

## 综合选择及完成状态

保留原预定门槛：误差优于每折IDW／GP较强者、H_point≤基线+.05m、risk Recall≥基线−.02、risk FPR≤基线+.02，以及严格多数不同场地改善。弱参照不进入晋级候选池。

**七个新增科学方法均未通过每折综合门槛，未扩大外层测试。** 例如图Huber在前两折厚度增量.05469m略超过.05m护栏，第三折误差未胜GP；FPCA核岭在第三折改善误差和厚度，但risk FPR超过GP护栏；配准前两折主要失败于校准误报。没有为追求成功放宽门槛。

“本轮新增候选未晋级”不取消已有v0.4的选择，也不意味着这些结构方向毫无价值。当前仍是不同指标之间的取舍，v0.4的0.620528保持统一比较中的最低连续误差。[失败条件与选择](comparison/selection.json) · [逐场地配对](comparison/pairwise_by_site.csv)。

20项新增定向检查通过，九个新候选均完成全部60状态；没有改变旧算法参数。大权重及逐深度输出保留本地`runs/v5-exploration-20261014/`，本目录保存精简研究说明、来源、指标、配置与未收敛记录。
