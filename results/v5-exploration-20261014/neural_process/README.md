# 整根剖面条件神经网络：v0.5 单候选探索

本候选将每根已测 CPT 的 24 个深度值作为一个上下文对象，用 query-relative DeepSets 集合网络预测完整查询剖面。它不使用 Transformer、TabPFN、IDW 残差或 GP，不增加目标位置的已测参数。该方向用于检验：学习跨场地的完整剖面条件映射，是否比已有逐深度表格表示更有效。

## 已冻结设计

- 基础依据：[Garnelo 等的 Conditional Neural Processes，ICML 2018](https://proceedings.mlr.press/v80/garnelo18a.html)。原论文提出观察集合编码、置换不变聚合、查询解码结构；本实现是其小型确定性适配，**不是原论文的逐点高斯似然模型**。
- 每根标准化 log(qc) 剖面经 24→64→64 MLP 编码。每个查询位置与支持位置的相对 dx、dy 和距离，按固定 50 m 尺度做 signed-log/log1p 变换；保留物理尺度，去除绝对投影坐标原点。
- 拼接剖面编码与相对位置，经 67→64→64 MLP；对支持根做 mean 与 max 集合池化。池化后拼接显式深度，129→64→64→1 解码。共享深度解码器预测全部 24 个深度单元。
- 参数总数 **26,817**。只提供点预测，无原生概率/区间。后续统一校准属于额外评估层，不能称作网络原生不确定性。
- 使用既有 v4 源训练/验证轨迹；训练以场地轮换，每次一条 episode，剖面和深度取平均 MAE。源训练场地等权计算固定目标归一化统计。
- AdamW，学习率 0.001、weight decay 0.0001、梯度裁剪 1；每折最多 2,000 次更新；每 100 次验证，最少 400 次后按 4 次不改善早停。唯一种子 20261014+fold_id，无架构或参数搜索。
- 仅源 validation episode 场地等权 MAE 选权重；统一 60 状态的回放真值不参与训练/调参。目标场地只更新上下文，模型权重冻结。
- 使用 CPU 单线程；小模型反向训练耗时很短，时间主要在源 episode 数据组织。训练摘要中的 elapsed_seconds 只计优化循环及其验证。

## 解释与限制

源验证误差随训练下降，说明优化确实发生，但当前小型共享集合编码器在回放场地上倾向输出平滑的中间剖面。少量源场地、固定维度池化压缩和 MAE 对条件中位数的偏好，都可能导致极低值结构被平均掉；这只是机制解释，尚未用消融分离原因。本结果否定的是这一注册小型候选，不能推广为所有神经过程不适用。重复深度和 episode 不能作为新增独立场地计数。

四项信息边界检查通过：支持集合/查询顺序不改变预测；平移投影坐标不改变预测而改变米制尺度会影响预测；伪造 query 标签不影响预测；缺失整根深度、混入测试角色或训练验证组重叠会被拒绝。

复现入口：`python -m cpt_budget.v5.neural_process --config configs/v4.yaml --device cpu`。输出保留在独立 v5 目录，v0.4 及之前的冻结结果未修改。
