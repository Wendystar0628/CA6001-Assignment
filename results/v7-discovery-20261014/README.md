## 主方案为什么有效

1. **三角网插值先利用平面几何。** 在已测位置的Delaunay三角形内按重心坐标插值整根剖面；凸包外投影到最近边界边。该新强参照单独已有E=.607248/H=.585286，说明当前任务仍有尚未利用的局部几何结构。
2. **与支持集自适应结构模型等权融合。** 后者从当前已测CPT整根留一结果选择IDW、FPCA、形状配准和空间加权中位数权重。未作事件修正时，融合E=.592896，但点召回只有31.76%。
3. **把整根误差曲线作为联合变化原子。** 将当前已测CPT整根LOO-IDW误差以固定.5收缩加到融合基底上，保留同一原子贯穿24深度，构成有限完整曲线混合。
4. **直接对厚度作决策。** 计算各原子的低值格数，取加权中位数作为预测格数；按混合事件概率选择低值位置，只将需要翻转的格修改至±.05 log(qc)。这同时修复了厚度和部分点识别，E进一步降至.592435，Recall恢复到38.52%。

关键在于“逐点中位数的低值格数”不等于“整根曲线低值格数的中位数”。完整曲线模型给出了与累计厚度目标更直接的决策。加权中位数的L1最优性仅针对构造出的有限分布；不能据此宣称该分布就是真实后验。将IDW误差迁移到其他基底也仍是模型假设。

## 晋升规则是怎样确定的

按照用户要求，先完成85配置并观察实际收益与代价，再确定研发晋升规则；最后8个细化候选沿用此规则，没有继续改变它：

- 连续误差和厚度误差都优于IDW，**不要求最低提升百分比**。
- 在全部183个固定模型的连续误差、厚度、点平衡错误和风险平衡错误上处于Pareto前沿。
- 至少3/4个不同场地的连续误差改善。
- 点平衡错误允许比IDW高最多1个百分点；点FPR允许高最多2个百分点。
- risk Recall不低于IDW−2个百分点，risk FPR不高于IDW+2个百分点。

平衡错误=.5×(1−Recall+FPR)。上述小幅容差使厚度／连续预测收益可以与识别代价一起判断，而不是用一个很高的百分比否决所有方案。5个模型达到主线条件；其余9个Pareto候选保留作专项，不称为全面优胜。

**这是明确的事后探索性选择，晋升表示值得进入下一版研发和冻结确认，不表示已获得独立泛化证明。** 原综合门槛与v0.6的3%／10%目标没有被改写，仍以`legacy_*`保存供对照。新规则达到不等于每个模型都通过了所有旧的逐fold护栏。

## 这轮实际做了哪些新方向

| 新方向 | 实测判断 |
|---|---|
| 移动最小二乘／LAD／三角网局部几何 | 三角网成为有力新基座；LAD有厚度收益，MLS未获均衡优势 |
| 源垂向协方差协同克里金／LMC | 有局部厚度收益，原生90%区间覆盖仅42%–61%，不推荐作可靠区间 |
| 图核范数／梯度核范数／双调和／低秩细节 | 双调和、低秩细节有召回强项，但连续误差和误报有代价；120个ADMM状态均收敛 |
| 源训练整剖面多输出森林 | 1536棵树、约16.8s真实拟合，未获得竞争力，保留负结果 |
| 完整曲线有限混合分布 | 直接连接厚度目标，成为本轮主线核心机制 |
| Haar／DCT粗细分解 | 原始方法厚度好但幅度差；用其计数配强幅度后获得厚度专项候选 |
| 空间度量学习／源成对迁移 | 加Euclidean-all匹配对照后，多数收益由邻居数量解释，不夸大度量学习贡献 |
| 源厚度／事件头的当前场地适配 | 仅在已测整根LOO上作收缩校正，有厚度价值；原生风险头仍有较高误报 |

配置数量：初轮37（含匹配对照）＋第二轮40组合＋第三轮8风险头对照＋最后8定向细化＝93。候选不是93个互不相干的新算法；风险版本、消融和匹配控制均如实标识。

## 数据与证据范围

仍为60个冻结验证状态、种子17/29、预算5/7/9/11/13、2–8m的24格、1MPa事件。每模型8640深度行，但只有4个不同验证场地。先积分预算，再平均种子和同场地重复fold，最后不同场地等权，不能把深度行／重复预算当独立样本。

源学习只用对应train场地，目标适配只用当前已测CPT；LOO排除整近邻组及共坐标；query测量不进入预测或组合。共同风险校准仍为留勘察组交叉校准。独立风险头仅使用合法原生预测，未复制已校准OOF风险。

最后8个只作增量校准，前85配置的5100条状态、7个核心指标逐键完全相同，最大变化0。独立代理从原metrics重新积分并确认代表成绩、5个晋升名单、4场地权重和上述局部代价。56项定向检查通过。没有扩大成全仓库回归。

多轮搜索、晋升选择与成绩共用验证集，存在选择乐观偏差。**没有独立outer-test，没有统计显著性或节省补勘根数的证明。** 当前代码和记录可供冻结后的独立确认；本轮没有将科研候选部署为真实地质勘察决策系统。

## 复现与提交

运行依赖已准备的数据及v0.4–v0.6冻结产物。先执行各方法与组合模块，再运行统一评价。最终的增量步骤是：

```powershell
.venv/Scripts/python.exe -m cpt_budget.v7.frontier_joint
.venv/Scripts/python.exe -m cpt_budget.v7.evaluate --families frontier_joint --reference-output final --output final_extended
.venv/Scripts/python.exe -m cpt_budget.v7.promote --output final_extended
```

这里`final`是前85配置的完整同状态评价；`final_extended`包含全部93配置。归档`comparison/`对应后者。历史逐候选门槛表合并85＋8的原行；`legacy_selection.json`仅是最后增量的旧规则选择，不能误当作本轮晋升结果。

本目录保留指标、联合原子和计数决策、来源、参数、收敛与训练摘要。逐深度预测、大森林权重、源协方差和完整状态缓存留在本地`runs/v7-discovery-20261014/`；精简归档不是自包含的大模型数据包。
