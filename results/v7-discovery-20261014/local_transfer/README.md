# v7：源任务计数／事件头的少样本目标适配

本轮保留 v6 的 source-trained ExtraTrees count/event heads，不重新训练树。新机制是：利用**当前预算已经测得的完整 CPT 剖面**估计当地偏移，再向未测剖面预测。它不依赖验证 query 的标签，也不读取旧 OOF 风险分数。6 个候选及参数在运行前固定。

## 适配与组合

1. 对当前已测剖面按 `near_group_id` 相同或水平坐标重合（距离 ≤1e-8 m）建立连通分量。每次排除整个分量，以其余已测剖面为上下文，让源头预测被排除的完整剖面。
2. 计数偏差先在分量内取 `真实低阻力格数−源头预测格数` 的中位数，再跨分量取中位数；最后乘 `G/(G+10)` 收缩，`G` 为可形成独立 LOO 的分量数。
3. 原事件概率经过单调 logistic map `sigmoid(a*logit(p)+b)`。优化目标为各分量等权平均的二元交叉熵之和，加 identity prior `0.5*((a−1)^2+0.25*b^2)`；约束 `a∈[0,4]、b∈[−6,6]`。没有独立 LOO 上下文时保留 identity；优化失败亦回退 identity。
4. 分别组合 v4 最佳残差点模型和 v6 `support_stack_structural`：直接校正计数投影、校正计数与当前基底计数各占一半后投影、固定事件 DP，共 6 个候选。投影仅把需翻转符号的格子改到 ±0.05 log(qc)。DP 沿用 `tau=.5、potts=.25、cardinality=.25`，输出实际 MAP 点剖面与精确 Gibbs marginal。

所有厚度指标由最终点预测 `qc<1 MPa` 重新计算。count/half-count 候选的 `p_low_1` 是本地校准的源事件概率；DP 候选的 `p_low_1` 是其 Gibbs marginal。共同 evaluator 后续的留勘察组风险校准是另一步骤，不能把二者混称为同一概率。

## 结果

60 状态、每模型 8640 深度行、4 个不同场地。下表采用原预算曲线积分和独立场地等权汇总；这是反复使用验证集上的探索结果。

| 方案 | log-MAE ↓ | 厚度 MAE / m ↓ | 点召回 ↑ | 点误报率 ↓ |
|---|---:|---:|---:|---:|
| 本地事件 DP＋结构 stack | 0.611827 | 0.565267 | 0.232673 | 0.069800 |
| **本地半计数＋结构 stack** | **0.615529** | **0.504557** | **0.375881** | **0.088825** |
| 本地事件 DP＋残差 | 0.621787 | 0.572428 | 0.214083 | 0.069829 |
| 本地计数＋结构 stack | 0.627860 | 0.589518 | 0.366105 | 0.127683 |
| 本地半计数＋残差 | 0.627986 | 0.522786 | 0.365669 | 0.098214 |
| 本地计数＋残差 | 0.640304 | 0.589518 | 0.347682 | 0.129452 |
| IDW | 0.638586 | 0.630371 | 0.373767 | 0.072766 |
| v4 最佳残差 | 0.620528 | 0.630371 | 0.373767 | 0.072766 |
| 未投影结构 stack | 0.611865 | 0.612142 | 0.331223 | 0.062606 |
| v6 源半计数投影＋结构 stack＋GP risk | 0.623176 | 0.552246 | 0.423306 | 0.106282 |

**本地半计数＋结构 stack** 最适合继续组合：相对 IDW，连续误差约下降 3.61%、厚度误差约下降 19.96%，点召回基本持平，而点误报增加约 1.61 个百分点。相对未投影的结构 stack，连续误差略增，但厚度、点召回改善；应按任务权衡，而非只按连续误差排序。

事件 DP 的厚度改善伴随明显召回下降，不能仅凭其低 log-MAE 晋升。全量校正 count 的误报仍偏高，半计数保留基底判断的组合更有价值。最终公共风险结果和晋升判断由统一实验汇总给出，这里不预设通过条件。

因 v6 的结构 stack 计数投影用的是“源计数与原残差计数各半”，本轮 stack 半计数用的是“源校正计数与 stack 自身计数各半”，二者差异包含**目标偏差修正和计数基底变化**，不能把全部增益归因于校准单一因素。对于同一残差半计数，厚度从 v6 的 0.552246 m 降到本轮 0.522786 m，则由计数校正改变了最终低阻力格数。

## 运行与检查

- 运行约 37.8 s，CPU 单线程；60 个本地概率拟合均成功，没有重训 source trees。
- 4 项定向检查通过：near/co-location 连通闭包及行序不变性；单类别校准有限且单调；无独立上下文安全回退；完整分量 LOO 和计数收缩。
- `method_protocol.json` 是固定方法说明；`contexts/` 保存每状态的 LOO 排除记录与拟合参数；`adaptation_summary.csv` 汇总偏差、收缩与概率参数；`profile_decisions.csv` 记录源计数、校正计数和实际点厚度对应格数。
- `point_metrics.csv`、`point_macro.csv`、`point_sites.csv` 仅为点指标；正式风险指标以统一比较输出为准。

```powershell
.venv/Scripts/python.exe -m cpt_budget.v7.local_transfer
.venv/Scripts/python.exe -m pytest tests/test_v7_local_transfer.py -q
```

概率校准参考 [scikit-learn 官方说明](https://scikit-learn.org/stable/modules/calibration.html)；采用 logit 概率而非任意 score、保留 identity prior 的设计也参考 [Kull 等关于二元概率校准的讨论](https://proceedings.mlr.press/v54/kull17a.html)。本实现是正则单调 logistic calibration 的项目适配，并非 beta calibration 论文复现。
