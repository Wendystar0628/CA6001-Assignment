# v7 整剖面协同克里金 / 多输出 Gaussian 条件化

五个候选均完成共同的 60 个验证状态，每个输出 8640 个深度单元；3 折只有 4 个不同验证场地。结果按预算 AUC、种子、折、不同场地等权聚合，不能按全部 60 行直接平均。没有运行独立外部测试。

## 方法及边界

每个源训练场地内部先减去本场地的平均 24 深度剖面，再构造协方差；各场地贡献等权。三折各使用 262 根训练剖面。源模型不读取目标验证/测试场地。目标截距是当前已揭示 CPT 的平均剖面，条件化只使用这些已揭示标签；预测入口只需查询几何。

水平核为 Matérn 3/2，以已揭示位置的非零两两距离中位数为基础尺度。共同观测 nugget 为源垂向平均方差的 3%，另有数值 jitter。固定候选为：

- `v7_cokriging_full`：源完整协方差向对角矩阵收缩 10%，与单一水平核作 Kronecker 积。
- `v7_cokriging_short`：相同模型，水平尺度为基础值的 0.5 倍。
- `v7_cokriging_rank6`：保留前 6 个源垂向特征，剩余方差放入深度对角项。
- `v7_cokriging_lmc`：前 3 个垂向特征用 1.5 倍长尺度，其余特征及收缩对角项用 0.5 倍短尺度；两个有效多输出核相加。
- `v7_cokriging_loo`：只在目标已揭示支持集中，按整剖面留出 MAE 从水平尺度倍数 0.35、0.7、1.4 中选择；留出同 near group 和重复水平坐标的所有剖面，重算剩余支持集的截距及几何尺度。

和旧固定 FPCA 系数回归相比，这里没有把全部输出硬截断到有限子空间，并能给出明确联合 Gaussian 条件化公式；LMC 允许不同垂向模式拥有不同横向相关长度。完整可分离核在全部深度均被观测、且 nugget 为零时会发生跨输出协方差在均值公式中的抵消，因此不能仅以“多输出”命名宣称额外能力；本实验具有正 nugget，LMC 还具有不同的水平核。

对照 IDW：log-MAE 0.638586、点厚度 MAE 0.630371 m、点召回 0.373767、点误报 0.072766。`full` / `lmc` 的点厚度更好，但连续误差较大；收益主要来自 Marshland 和 Tauranga，Lower Hutt 的厚度反而退化。`short` 在 3/4 场地的连续误差改善，平均改善很小。支持集 LOO 没有带来更好的全局表现。五者均未超过既有残差模型的连续误差 0.620528；保留全部负结果，不将“可用于组合”写成已经全面取胜。

原生概率按真实 Gaussian 边缘均值和方差推导，包含观测 nugget；量化区间不是借用别的模型区间。它们条件于估计得到的目标截距和源协方差，未计入这些估计量的不确定性。**名义 90% 区间实际只有约 42%–61% 覆盖，严重低覆盖，不能作为可靠风险保证。** 期望厚度是逐深度边缘事件概率求和，和点厚度是不同指标；这里没有给出联合厚度置信区间。

## 实现与验证

实现：`src/cpt_budget/v7/cokriging.py`。六项定向测试覆盖源场地等权、协方差半正定、与直接 Gaussian 线性代数一致的均值和方差、查询行序与标签隔离、源目标隔离、同 near group 整体留出。最大数值解残差为 9.25e-14。全部矩阵均完成 Cholesky 求解；没有求解失败，也没有靠跳过状态拼接结果。

```powershell

.venv/Scripts/python.exe -m pytest tests/test_v7_cokriging.py -q
```

`native_macro.csv`、`native_site_metrics.csv`、`native_site_deltas_vs_idw.csv` 保留聚合与逐场地结果。原始候选输出、context 参数、协方差和 run_summary 均在本目录。
