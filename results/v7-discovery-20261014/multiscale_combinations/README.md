# v7 第二轮：Haar 厚度计数与强幅度组合

本轮在运行前记录 10 个固定候选，以第一轮 Haar 候选的厚度优势补充强连续预测器。没有读取查询真值，没有用结果回头调整这 10 个候选。

## 两种组合

**8 个厚度计数组合。** 基础幅度选 `v7_simplex_linear` 或 `v6_fpca_residual_w050`，结构成员选 `v7_haar_krr_nearest` 或 `v7_haar_krr_median`。每根预测剖面计算两者 `log(qc)<0` 的格数，按 Haar 比例 0.5 或 1.0 混合，`floor(count+0.5)` 取最近整数（半数向上）。按基础预测从低到高、同值按深度从浅到深选出目标数量的格点。只有类别改变的格点被赋值 −0.05 或 +0.05，其他幅度原样保留。

这是一种预测厚度约束，不是真实厚度约束。比例 1.0 时新预测的点厚度与 Haar 成员逐根相等，但低阻力的具体深度位置仍由基础预测排序决定，因此其召回/误报可以不同。

**2 个 Haar 系数组合。** 保留 simplex 预测的前 3 个粗尺度 Haar 系数，与上述两个 Haar 预测的 21 个细节系数组合，再作可逆重建。此组合不强制厚度相同。

所有候选都携带相同的 **GP 原生 `p_low_1` 独立辅助风险头**；该概率不是新点预测的 CDF，不代表两者共享一个联合预测分布。统一校准可以评价这个 GP 风险头，但不能把风险改进归功于 Haar 计数编辑，也不能把由该概率求得的期望厚度说成新点预测自己的概率厚度。

## 完整点结果

每个候选均为 60 状态、8,640 深度行，预算积分后按 4 个不同场地等权；全表都是实际结果。校准风险结果由主比较模块提供。

计数组合在保留基础幅度的同时取得较低厚度误差。纯系数拼接的连续误差明显较高，应保留为负结果，不与更好的计数组合混写。此处不自行设定晋升门槛，全部候选交由主流程统一评价连续误差、厚度、点识别和独立 GP 风险头。
