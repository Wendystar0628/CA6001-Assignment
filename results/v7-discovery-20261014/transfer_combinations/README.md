# v7 第二轮：固定目标适配计数，交换幅度与风险头

第一轮 `v7_local_half_count_stack` 的厚度误差为 0.504557 m。本轮直接读取该模型的合法点预测，逐剖面统计实际 `log_qc<0` 格数，并固定这些计数。没有重新训练、重新校准或改变 count 参数。

固定的 6 个候选由三种幅度基底与两种风险头组成：

- 幅度：`v7_simplex_linear`、其与 v4 最佳残差各占 50% 的平均、`v6_fpca_residual_w050`。
- 风险：第一轮 count 模型自身的本地校准原生 `p_low_1`，或冻结 GP 的原生 `p_low_1`。
- 在每种幅度基底中按预测值从低到高选择固定数量的低阻力格；仅把需要翻转符号的格子变成 ±0.05 log(qc)。风险头独立于点幅度，不转移任何预测区间。

协议在本轮运行前写入 `method_protocol.json`；候选方向依据第一轮结果提出，因此属于验证集上的继续探索，不能当成独立确认。生成器只读取预测值、原生概率和行键，未读取 query truth 或旧 OOF risk。

## 点结果

每个候选覆盖 60 状态、360 剖面、8640 深度行；所有剖面的最终格数与来源模型完全相同，故厚度误差严格保留。两种风险头不改变点结果。

| 幅度基底 | log-MAE ↓ | 厚度 MAE / m ↓ | 点召回 ↑ | 点误报 ↓ |
|---|---:|---:|---:|---:|
| **50% simplex＋50% 最佳残差** | **0.606581** | **0.504557** | 0.347249 | 0.091310 |
| simplex | 0.615857 | 0.504557 | 0.320343 | 0.092078 |
| 50% FPCA＋50% 最佳残差 | 0.618620 | 0.504557 | **0.374826** | **0.090124** |
| 来源：本地半计数＋结构 stack | 0.615529 | 0.504557 | 0.375881 | 0.088825 |
| IDW | 0.638586 | 0.630371 | 0.373767 | 0.072766 |

`v7_transfer_simplex_residual_*` 相对 IDW 的连续误差约下降 5.01%、厚度误差约下降 19.96%，代价是点召回少约 2.65 个百分点、点误报多约 1.85 个百分点。它是可用的幅度互补方案，不能仅根据平均连续误差判定全面优胜。

FPCA50 基底保持了接近 IDW 的点召回，但连续误差比第一轮结构 stack 来源略高，点误报也稍高。公共风险指标由统一 evaluator 分别评价 `localrisk` 和 `gprisk`，本文件不预设晋升门槛。
