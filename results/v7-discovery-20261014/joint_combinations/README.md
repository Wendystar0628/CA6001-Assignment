# v7 第二轮：完整曲线分布与新幅度基底组合

在第一轮结果启发下，固定选择 3 个幅度基底：simplex 分片线性空间插值、既有 `support_stack_structural`、simplex 与最佳残差的 50/50 均值。分别搭配 analog/error 两种完整曲线原子并采用 hmedian 决策，得到 6 候选；另测试 simplex 的两种逐点 median 决策，共 8 候选。

所有分布参数保持第一轮固定值：原子缩放 0.5、支持坐标中位数尺度 Gaussian 权重、完整 near_group/同坐标 LOO 排除、±0.05 logqc 事件过阈值。没有搜索带宽、缩放或风险校准参数。本轮是复用验证集的自适应探索，不是新确认实验。

## 点指标结果

每候选完成 60 状态、8640 深度单元。下表使用统一预算积分与 4 个不同场地等权聚合；风险校准交由主 evaluator 完成。

| 候选 | log-MAE | 厚度 MAE/m | 点召回 | 点误报 |
|---|---:|---:|---:|---:|
| simplex/BEST50 + error hmedian | 0.598844 | 0.525228 | 0.376827 | 0.081877 |
| simplex/BEST50 + analog hmedian | 0.601437 | 0.577311 | 0.352058 | 0.072640 |
| simplex + analog hmedian | 0.607915 | 0.553385 | 0.381151 | 0.079499 |
| simplex + error hmedian | 0.608434 | 0.531413 | 0.390704 | 0.089093 |
| simplex + analog median | 0.611464 | 0.596029 | 0.349939 | 0.074196 |
| stack + analog hmedian | 0.612355 | 0.547363 | 0.418877 | 0.078527 |
| stack + error hmedian | 0.613547 | 0.494792 | 0.392439 | 0.087519 |
| simplex + error median | 0.626723 | 0.563965 | 0.371909 | 0.081276 |

相对单独 IDW：

- **simplex/BEST50 + error hmedian**：连续误差下降 6.223%、厚度下降 16.680%，点召回略升、误报增加约 0.91 个百分点。4 个场地连续误差均改善；Lower Hutt 厚度误差从 0.1328 m 增至 0.2109 m。
- **stack + analog hmedian**：连续误差下降 4.108%、厚度下降 13.168%，点召回增加约 4.51 个百分点、误报增加约 0.58 个百分点。
- **stack + error hmedian**：连续误差下降 3.921%、厚度下降 21.508%，点召回增加约 1.87 个百分点、误报增加约 1.48 个百分点。

这些平均改善并没有消除场地间的定位代价。第一行 Marshland 点召回仅 0.0809、Tauranga 点误报 0.1922；stack+analog 的 Lower Hutt 厚度误差达到 0.3021 m。不能仅凭本表宣称全面晋升。

## 联合分布与可追溯输出

2880 个候选剖面决策全部保存；19440 个曲线原子的权重、来源、24 位事件 mask 与低阻力计数均在 `joint_atoms.csv`。所有 hmedian 候选实际点计数均等于完整联合厚度中位数；1279 个候选剖面的联合厚度中位数不同于逐点中位数计数。

`p_low_1` 始终来自该候选实际使用的同一完整曲线混合。相同 simplex/atom 组合的 median 与 hmedian 决策共享概率，但输出不同的点决策；没有复制旧校准概率。没有继承 GP 的区间或宣称这些有限原子是已校准后验。

方法及原始研究来源沿用 `../profile_distribution/README.md`。该空间有限混合是明确的迁移假设，LOO-IDW 残差并非新基底自身的预测残差。实验不包含外层测试。

运行：`.venv/Scripts/python.exe -m cpt_budget.v7.joint_combinations`。新增 2 项测试通过，覆盖安全基底向量、同一 joint 分布的不同决策一致性、真实计数约束及 query 标签拒绝。
