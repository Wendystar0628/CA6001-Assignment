# Formal adaptive CPT report

[Word report](CA6001_Adaptive_CPT_Report.docx), [PDF report](CA6001_Adaptive_CPT_Report.pdf) and [readable Markdown](CA6001_Adaptive_CPT_Report.md) contain the formal coursework report. The final document has one cover page and ten content pages, including references. The retained course template determines the section order, A4 geometry and Times New Roman type.

Edit `report_template.md` for narrative structure, `references.md` for APA references and `report_facts.json` for verified prose, tables and figure links. The fact file records the experiment files used. Results are from `results/adaptive_v1`; archived v0.9.1 scores are not used as new adaptive evidence.

Build in the project environment with the optional report dependencies installed:

```powershell
.venv/Scripts/python.exe reports/build_adaptive_report.py
```

The default build requires `status: final` and complete result text. A temporary draft can be made with `--draft`; it is written only to `.qa/`. The final PDF is exported from the Word document after checking pagination and the rendered pages.

Figures are generated by the adaptive display module and referenced through relative paths. Keep the original assignment template in the project root. Student names on the cover are editable fields to complete before submission.
