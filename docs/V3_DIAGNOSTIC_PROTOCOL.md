# CPT v0.3 诊断与合法适配共识

冻结日期：2026-10-14；起点：`v0.2-validation` / `fdb2817`；分支：`feat/v0.3-diagnostics`。本轮研究现有 TabPFN 未胜过空间基线的原因，寻找对原目标有利且不泄漏的适配。结论保持探索性，不把已查看过的场地重新称为独立确认性测试。

## 固定口径

- 保持相同原始数据、勘察组划分、2–8m、24单元、1MPa以及5/7/9/11/13根预算。
- 模型比较复用v0.2验证回放的maximin支持集、固定评价位置，fold 0/1/2、种子17/29，共60个预算状态。所有候选必须覆盖同一矩阵。训练只读fold的source train，早停和超参数选择只读source validation；不读取outer test成绩选择方法。
- 预测器只接收observed及无标签query。真值由统一评估器隔离持有；固定episode过拟合/教师拟合属于训练诊断，不进入泛化或成本结论。
- 模型指标保留原log-MAE、H_point、原点Recall/FPR及原生分布表现；另外统一做与v0.2相同的留勘察组风险校准。不能把新增校准或门槛定义带来的变化算作模型收益。
- 60个预算状态属于12条曲线、6个fold/site组合、4个不同验证场地。先作预算归一化梯形积分，再平均种子、重复场地的fold，最后等场地汇总。
- 强对照保留原IDW、GP、v0.2原始/微调TabPFN；新增独立24特征XGBoost作表示对照。不得删除失败场地或选择有利阈值。
- GPU同一时刻仅一个实验进程；脚本实现、源数据准备和CPU实验并行。

## 预登记小矩阵

| 实验 | 固定做法 | 能回答的问题 |
|---|---|---|
| 训练链路A | fold 0首个合格source-train情景，5根support、2根完整query，固定200次更新，LR 1e-5、CRPS+MSE | 固定真实目标能否被优化，训练和正式推断是否一致 |
| 训练链路B | 相同情景，以IDW产生query教师目标，从原始权重独立重启，同样200次更新 | 是否能学会简单插值目标；伪标签只用于机制诊断 |
| TabPFN残差 | 目标context标签为整位置留一IDW残差，query先IDW后加TabPFN残差；alpha固定候选0/.25/.5/1 | 保留基线结构能否减少错误修正 |
| source context | 每个源训练场地固定选一根真实episode query作为上下文银行，加上目标已测context；使用原始权重 | 历史实例直接进入上下文是否比仅进入权重更有效 |
| honest context | 已测CPT按固定几何规则分约60% anchor和40%标签context；context/query特征都从同一anchor构造 | support留一和query使用全支持的分布差异是否重要 |
| 独立XGB24 | 与新版TabPFN相同24特征、相同源训练episode及场地等权；深度4、LR .05、最多500树、验证早停30 | 新表示的信号能否被普通树模型利用 |

残差alpha=0恢复IDW点预测，不伪造确定性区间。正alpha必须平移/缩放整个残差分布，并在对应变换后的阈值处计算CDF；不可直接沿用残差的1MPa概率。source context只选train-role真实样本，不按验证成绩手选场地。honest context牺牲部分邻域信息，失败也必须保留，因为它是机制诊断。

source bank按目标预算选择support根数最接近的训练episode，再按固定seed与ID散列打破平局；每预算每合格源场地仍仅一根完整query。该规则只看ID与数量，不看目标真值或验证成绩。源context工厂明确将target_context_only设为false，区别于冻结的v0.2目标场地独占上下文协议。

## 追加的机制候选（原残差结果之后登记）

2026-10-14，原残差alpha=.25在60状态完成后，发现连续误差下降但前两折H_point由.6875升至.790365m、原点Recall由.3633降至.2828。为检验改善是否能与基线低值判断兼容，追加**仅点预测的阈值保护残差**，alpha固定为.25/.5：先IDW＋残差修正，再将预测限制在IDW预测相对ln(1MPa)=0的原侧；IDW预测为负则上界−1e-9，否则下界0。它不读取隐藏真值，不修改阈值，不排除失败位置。

该候选不是最初矩阵的一部分，结果明确标为探索性追加。它保持IDW原来的点分类及H_point，因此不能宣称自己改善了低值识别；仅检验连续剖面能否在不改变基线点判断的条件下更准确。不给这种点裁剪输出伪造原生分布，统一风险校准仍单列且独立检验。不得因为这个规则满足点护栏就跳过原定OOF风险及多数场地门槛。

## 选择与扩展

完整两种子结果齐全后，候选与每折IDW/GP最强验证基线配对比较。主要log-MAE需改善，H_point不超过基线+.05m，风险Recall不低于基线−.02，风险FPR不超过基线+.02；同时报告原点指标，不能掩盖其退化。alpha只在预登记集合内按完整验证选择，保留alpha=0回退。

全局要求：三折齐全、不同验证场地中严格多数改善、失败折保留maximin/基线回退。只有通过者才考虑扩大剩余验证种子43/71/101或下一轮选址；追加的同场地种子不能描述为新的独立场地证据。本轮不以实现成本节约为必须得到的结果，不修改旧冻结质量目标来凑达标。不通过时交付诊断证据、实现与负结果。
