# v0.8 领先方案的工程优化与性能比较

2026-10-14。整合既有均衡、厚度、识别、结构组合与TabPFN残差方案，五个优化分工并行；另一个分工负责统一串行真实性能基准，主代理集成完整推理管线和Markdown报告。直接在main提交推送，保留用户未跟踪notebooks。

## 两种优化分别评价

1. **等价工程优化**：权重、estimator、精度、阈值和算法决策不变，优化重复邻接/LOO、数组布局、批量线性代数、配准缓存、中位数解码等。完整60状态检查点值、低阻力标签与原生概率差异。
2. **质量适配**：只用当前已测CPT整近邻组LOO作权重、误差收缩、计数或定位可靠性适配；与原算法分开命名，全部失败和取舍保留，不称为数值等价加速。查询真值不进入适配。

## 固定的准确度评价

沿用相同60状态、24深度格、2–8m、1MPa、4不同场地、预算5/7/9/11/13与种子17/29，按预算AUBC→种子→重复fold的同场地→不同场地等权汇总。纳入v0.7全部183个参照，再比较20个新配置。历史弱基线、IDW、GP、XGBoost、原TabPFN及其微调/残差/FPCA/图组合均保留。

结构组合附与原版相同的GP原生风险头；均衡、Haar和识别的前后对照使用同一个独立经验图风险头；joint原生概率版本额外保留。风险仍统一交叉校准，避免把替换风险头的变化当作点工程优化收益。完整运行管线另外现场重算该经验风险头（TabPFN残差＋图Huber＋LOO经验CDF），不以历史预测文件代替推理。

原有晋升规则只供历史对照，本轮不新增高提升门槛。默认采用保持质量的等价快实现；质量适配按实际误差、厚度、召回和误报取舍报告。所有验证仍来自反复使用的场地，不是独立确认，也不证明补勘根数节约。

## 正式运行时间基准

优化开发与质量运行全部结束后，统一单线程CPU、同一RTX4080机器串行测量。取固定12状态：3fold×每折2场地×seed17×预算5/13。每状态预热1次，再3次真实condition/predict；CUDA在计时边界同步。工厂初始化、显式权重加载、条件化和预测单列；不将冷参考与热优化版比较。

- 弱中位数、IDW、GP测真实现场推理。
- 结构组合、Haar、TabPFN、完整均衡点路径测自身完整point路径。
- joint/recognition算子用现场IDW生成相同幅度输入，该准备耗时单列，算子时延不冒称完整系统时延。
- 完整均衡系统包括实时结构点预测、整曲线决策、TabPFN/图/经验风险头；外部验证校准拟合和文件I/O不算在线推理。

median与p95来自36次异质热态样本，p95仅描述本次样本，不能当作稳定尾延迟保证。配对加速比按相同状态的前后中位数计算。RSS是绝对进程工作集而非模型专属内存；CUDA peak allocated与保留缓存分开解释。

最终准确度结果、数值等价证据和性能证据各自保存，不从并行开发期计时得出正式速度结论。最后的报告需要同时呈现质量保持、真实速度收益及局部场地退化。
