# CA6001 CPT 结果诊断与改进路线

当前差距主要来自**预测目标、特征表示和选址目标之间的错配**，同时存在尚未充分探索的训练配置。没有发现“微调没有更新权重”“阈值空间解码错误”“查询标签进入模型”等足以一键解释失败的错误。也没有证据证明 TabPFN 或主动补勘这两个大方向已经失败。

更接近原核心预期的路线是：先修正实际丢失的信息和评价解释，再建立有低值识别护栏的空间预测器，随后用整根 CPT 的预期信息收益选址。仅增加集成数、重启次数或训练时间，目前不足以支持相对最强基线稳定改善10%的判断。

本次结论综合冻结实验、官方实现与原始论文，以及只使用源验证场地的新探针。新增探针均属探索性验证；原 `v0.1-results` 的模型、配置与结果没有被替换。日期为2026年10月13日。

## 已确认的问题及其含义

### 物理尺度没有按设计意图进入 TabPFN

当前特征将水平距离除以场地几何尺度，再单独加入恒定的 `log_geometry_scale`。但每个 context 只来自一个场地，TabPFN 的默认常量列移除会删掉这一列。

真实 New Lock 的5根支持集，16列经过该步骤只剩11列；把全部坐标和几何尺度同时放大100倍，留下的支持／查询特征最大差异仅约 `2.9e-13 / 4.6e-13`。因此这种情况下模型实际无法区分“同样相对布局、绝对间距相差100倍”的场地。被删除的其他列包含有效标记和支持数，它们可能本来就是冗余信息；问题不在列数减少，而在设计希望保留的物理信息确实消失。[官方预处理入口](https://github.com/PriorLabs/TabPFN/blob/v9.2.0/src/tabpfn/preprocessing/pipeline_factory.py)

这是可修正的表示与预处理适配问题。其对性能的影响尚未量化，IDW本身也对统一尺度变换不敏感，不能由此保证修复后超过IDW。下一版必须检查物理距离、相邻深度变化等信息能否穿过**完整预处理流程**，不能只在原始表中多加一列。

证据：[实现诊断](../.research/diagnosis_20261013/implementation/FINDINGS.md)、[数值诊断](../.research/diagnosis_20261013/implementation/diagnostic.json)；涉及 `features.py` 与官方 `RemoveConstantFeaturesStep`。

### 当前学习目标没有充分约束低值漏判

训练优化分布负对数似然，checkpoint按log-RMSE选择；正式低值判定却是点中位数低于1MPa，经济达标还要求厚度和Recall同时通过。改善前两个目标并不保证后两个目标改善。

同为maximin、13根，在七个有阳性场地上，Recall宏平均为：IDW **0.272**、GP **0.218**、微调TabPFN **0.058**。微调在Hollywood、Lower Hutt、Marshland的平均Recall均为0。其AP仍为0.410，接近GP的0.437，说明排序中保留了一些低值信息，但以分布中心作低值判定遗漏了大量事件。

这不是单纯运行速度或训练轮数的问题。更适合的候选是分别处理连续剖面重建和低值风险：保留1MPa物理阈值，使用经过源训练／验证校准的 `P(qc<1)` 作风险决策，明确漏判与误报代价。新的概率判定阈值必须与原点预测指标分列，所有概率模型获得同等验证机会，不能只调主模型、只报Recall而省略误报。

微调模型的期望厚度MAE为0.5201m，低于其点厚度MAE 0.6806m，但仍差于GP期望厚度的0.4713m。概率确实值得利用；这不构成在测试后直接替换原主指标的理由。

证据：[场地与目标诊断](../.research/diagnosis_20261013/data_objective/README.md)、[场地终点指标](../.research/diagnosis_20261013/data_objective/site_final_metrics.csv)。

### 局部宽区间没有直接衡量一根 CPT 的全场地价值

当前策略最大化候选自身的区间宽度，跨过1MPa时再加权。它没有计算补测这根CPT之后，其他位置的预测或低值识别能改善多少；第二点也没有扣除第一点已提供的信息，只做距离避让。

冻结实验的40个首轮同信息场景中，微调版阈值策略与普通不确定性策略有 **80%** 选中完全相同的两点，分数平均Spearman为0.937，约65.6%的候选深度区间跨阈值。阈值附加项经常没有提供足够的新区分。

同一候选池内，按距已测位置的最近距离从近到远排名：maximin选点平均位于93.8百分位，微调普通宽度策略为25.6，阈值策略为27.0。邻近加密不一定错误，但当前评分无法证明这种加密比补齐其他区域更有价值。GP的含噪预测区间适合描述未来观测，却不自动等于新增观测可以消除的不确定性。[积分后验方差的官方实现](https://botorch.readthedocs.io/en/stable/_modules/botorch/acquisition/active_learning.html)

证据：[首轮重合度](../.research/diagnosis_20261013/acquisition/frozen_first_round_summary.csv)、[选点几何位置](../.research/diagnosis_20261013/acquisition/frozen_selected_geometry_summary.csv)。

### 原经济门槛可计算 但典型质量的解释不成立

原设计分别取两个验证场地的log误差、厚度误差、Recall中位数，再要求三者同时满足。每个指标单独典型，并不意味着组合后仍然典型。

三折中，产生这些门槛的GP＋maximin＋13根自身都只有 **2/10个验证seed实例** 联合达标；先平均种子后，均为 **0/2个验证场地** 联合达标。例如一个场地通过厚度条件却不通过log误差，另一个相反，拼接中位数后两个场地都过不了。

因此“达到典型13根基线质量”的命名和门槛构造需要重新审视。代码忠实执行了蓝图，这不是计算bug。门槛过严、跨场地难度不同和算法实际漏判共同使经济可比较样本稀少；不能只挑一个原因解释全部结果。

40个测试配对中，7个双方达标里的5个是全阴性机场，两方法初始5根已达标，节约空间为0；其余2个本方法分别多用6根、4根。修正门槛是改善评价有效性，不能把放宽门槛产生的达标增加算成算法提升。

下一版应在验证阶段检查**联合可达性**，选取可解释的参考质量向量或预先固定的一组质量情景，并保留连续预算曲线与全部未达标实例。旧目标结果继续保存；不根据测试表现为每个场地定制门槛。

证据：[联合达标表](../.research/diagnosis_20261013/data_objective/validation_joint_attainability.csv)、[验证参考指标](../.research/diagnosis_20261013/data_objective/validation_reference_site_metrics.csv)。

## 工程优化仍然值得做的部分

三折正式微调只有140/150/150步，每折约两分钟。最佳checkpoint时，固定episode与query组合覆盖率分别约62.0%、92.3%、66.6%；当前epoch不是遍历全部查询组合的一整轮。训练任务多样性和覆盖仍有改进空间，但验证曲线已经出现平台或回退，简单重复相同任务可能继续过拟合。

锁定版本官方微调类默认使用CRPS＋MSE、训练／验证2个集成成员、最终推断8个；当前适配器使用纯NLL与1个成员。两者都是合法配置，官方默认也不是本任务的最优保证。值得做的是保持v2权重和分组，比较损失、完整查询轮换及有限更新预算。官方辅助MAE作用于分布均值，不能把它误称为直接优化当前中位数MAE。[官方v9.2.0微调实现](https://github.com/PriorLabs/TabPFN/blob/v9.2.0/src/tabpfn/finetuning/finetuned_regressor.py)

训练时继续保持场地等权，避免为了“看完数据”让New Lock支配梯度。增加场地内遮蔽情景不会增加独立场地数。推断缓存、并行和更大显存只能降低计算成本，本身不会改变现有预测的科学质量。

## 推荐的改进顺序

### 先建立兼顾剖面与低值风险的预测器

保留IDW作为强对照和可退回的空间估计，优先做两个有明确因果目的的候选：

1. **任务适配的TabPFN。** 修正物理／垂向信息表示，检查完整预处理；保证各固定查询组合获得合理曝光。在保留概率分布损失的同时，比较官方CRPS＋MSE和带低值概率辅助目标的版本。选择checkpoint时同时看剖面MAE、厚度、Recall/AP/FPR及区间可靠性，不只看RMSE。
2. **受约束的IDW残差模型。** 使用 `log(qc)=IDW+α×残差修正`，α在源验证中选择，包含0这个候选；残差训练必须来自整根留出任务。加入邻近深度变化等真实可用结构，并以低值漏判和厚度误差作护栏。朴素残差XGBoost已经失败，不能只换一个更大残差网络就假定有效。

若学习残差分布R，平移后的低值概率是 `F_R(log(1MPa)−IDW)`；对残差进行收缩或混合时需要重新检查概率可靠性，不能把α趋近0解释为观测不确定性也趋近0。期望厚度可以由校准后的边际概率求和，但不能据此制造厚度联合置信区间。

空间先验与TabPFN结合有相关土壤预测证据，但该研究要求至少50个空间样点，并非本项目5–13根CPT；其IDW先验与kriging先验的扩展对照也很接近，不能直接借用论文中的增益幅度。[Kriging prior Regression原论文](https://arxiv.org/abs/2509.09408)、[作者代码](https://github.com/JonasSchmidinger/Kriging_prior_Regression)

### 再把选址改为预期减少多少损失

最值得下一步验证的是 **面向低值风险的整根CPT序贯不确定性削减**，即block-SUR，而不是把当前区间分数再乘一个经验权重。

其判断依据为：

`候选价值 = 当前全场地预期损失 − 测量这根CPT后的平均预期损失`

预期损失同时包含整体重建误差与低值漏判／误报风险；参考位置及权重只依赖事先可知几何。先用ALC或几何规则筛出少量候选，再从GP联合后验抽取相关的整根剖面作为可能测量值，计算条件更新后的收益。第二根的价值应考虑第一根已提供的信息，仍然在两根都确定后才揭示真实测量。

可直接复用现有GP、回放和矩阵计算；候选评分内冻结核参数，真正得到新测量后再重拟合。初版不必为每个假想剖面重新运行TabPFN。若采用GP选址、IDW或TabPFN作最终预测，应明确称为双模型系统，并分离模型效应与策略效应。

SUR针对最终风险选择观测的思路有原始研究支持；批次中先更新协方差以减少冗余也有明确方法依据。但CPT整块观测、地质模型错设和本项目多条件达标均需自行验证，不能套用原论文的保证。[Bect等的SUR研究](https://arxiv.org/abs/1009.5177)、[Gotovos等的level-set与批选择研究](https://www.ijcai.org/Proceedings/13/Papers/202.pdf)

### 只有错误确实集中于层界时才升级非平稳模型

源趋势＋单一平稳核难以表达不同土层的尺度和倾斜边界。CPT专门研究中的混合GP把层界识别与分层空间变化联合建模，2026年论文在Groningen数据和模拟地层上报告相对GP的改善；2024年前期研究也明确报告真实CPT上的局限。[2026年CPT非平稳混合GP](https://repository.tudelft.nl/record/uuid:155780dc-79f0-4fea-8e71-dbc942dd4bc6)、[2024年研究](https://repository.tudelft.nl/record/uuid:21030711-09de-406e-b72f-b708956aa665)

它适合作为后续竞争路线。可以先尝试少量平滑深度分段和从源场地学习的参数范围；不应在仅5根已测CPT上无约束地拟合复杂层界。当前不建议同时新建GNN、强化学习选址或更大的语言模型。

## 下一轮实验如何作决定

| 顺序 | 小规模工作 | 进入下一步的条件 |
|---|---|---|
| 1 | 冻结新版联合质量定义、风险代价和特征表示；验证物理信息确实进入模型 | 门槛联合通过率有明确含义，所有模型使用相同规则；原结果保留 |
| 2 | 在全部源验证场地比较原模型、任务适配模型、受约束残差模型；先用两个固定种子及5–13全预算 | 连续误差优于经同等调优的IDW/GP，并且厚度与Recall/FPR不出现明显退步；否则不扩大 |
| 3 | 固定通过第2步的预测器，比较maximin、当前阈值策略、block-ALC和风险-SUR | 改善贯穿预算曲线与多数验证场地；不能只赢第一轮或只赢一个指标 |
| 4 | 锁定少数候选，扩大种子并完成新版结果 | 所有实例、未达标、阴性场地及计算成本均报告；按预先指定指标检验10%目标 |

已经用当前外层测试结果诊断和构思新方法，后续不能继续把它称为完全未触碰的确认性测试。最好补入满足同深度窗口与坐标要求的独立场地，或在项目开始新一轮时设立新的独立验证安排；如无法取得，应明确称为第二轮探索性改进，保留原固定划分结果供比较，不宣称未经验证的跨地质泛化。

当前8个回放场地、4个全球分组未核实场地，以及记录深度并非统一地层标高，仍限制结论范围。提高空间／地层信息质量，比单纯增加同场地seed更有价值。10%是继续检验的目标，不应成为必须通过调指标得到的数字。

## 推荐结论

近期优先投入**风险目标对齐、有效空间表示和可退回IDW的预测器**，并把**整根CPT的风险-SUR**作为新的决策主线。官方损失与有限训练预算比较用于排除配置欠优化；非平稳GP作为有针对性的后续路线。现有探针已表明，单独增加集成、套一层残差回归或改用ALC，都不足以承诺达到原核心效果。
