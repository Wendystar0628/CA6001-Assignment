# 方案选择依据

当前比较包括4个强弱基线、2个TabPFN组合、3个其他主方案和3个讨论方案，模型入口见`configs/catalog.json`。

- **基线4个**：常数中位数、3NN IDW、空间GP、同轨迹XGBoost残差。常数中位数提供弱参照，其余用于检验空间插值与学习残差的实际收益。
- **TabPFN组合2个**：FPCA＋训练残差的符号保护，以及图Huber＋训练残差的低值并集。前者兼顾连续误差与风险表现，后者具有较高的低阻力召回；选择同时考虑预测误差、厚度与识别指标。
- **主方案3个**：均衡方案、Haar厚度方案、高召回识别方案，分别对应整体误差、厚度预测与低阻力识别目标。识别方案采用recall60：点召回48.77%、厚度MAE 0.526855m，代价是点误报9.14%。
- **讨论方案3个**：simplex展示简单局部几何插值的竞争力；count_shrink的log-MAE最低，但厚度及耗时不及均衡方案；CNP呈现当前数据条件下复杂神经过程未优于强基线的负结果。

TabPFN残差、FPCA、形状配准、图Huber及整曲线决策也是组合内部的共享计算组件，不另计模型入口。其他主方案按点预测结构分类，其独立经验风险头仍使用TabPFN与图组件。

以上取舍基于相同60状态、4个验证场地，尚未经过独立测试集确认。完整指标、耗时范围与局部场地代价见[当前方案对比](../CA6001_CPT_当前方案对比.md)。
