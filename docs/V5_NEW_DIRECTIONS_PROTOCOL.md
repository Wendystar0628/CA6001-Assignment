# v0.5：新建模方向与低信息基线

日期：2026-10-14。按用户要求直接在main提交，暂停既有TabPFN／IDW／GP组合的工程调优，探索新的结构假设。候选与参数先在并行分工消息中确认，再运行；本文汇总这些约定，落盘时部分CPU实验已完成，不将本轮称作独立预注册确认性研究。

## 固定实验条件

复用v0.4所用60个验证预算状态：3fold、种子17/29、5/7/9/11/13根，4个不同验证场地；同一已测集合、固定评价位置、24单元、2–8m、1MPa。不读outer-test标签调参，不按结果选场地。保持Maximin布点，仅比较预测器。

原IDW／GP与v0.4全部候选继续保留。低信息参照用于说明深度与空间信息的价值，不能替代强基线；若弱参照在个别场地反而较好，也必须报告。

新方法只输出点预测，不伪造CDF／区间。原点Recall/FPR与统一留勘察组校准的risk指标分开。均先按预算积分，再平均种子、同一场地的重复fold，最后按不同场地等权。所有候选全矩阵齐全才形成整体比较。

## 本轮九个固定候选

| 方向 | 模型ID | 固定机制与参数 |
|---|---|---|
| 无输入关系的截距基线 | target_constant_median | 当前全部已测log(qc)的中位数，对所有位置／深度给同一个值；标准L1常数参照 |
| 仅垂向趋势基线 | target_depth_median | 每深度的已测中位数，不使用水平位置 |
| 功能型剖面低秩模型 | functional_fpca_krr | 源训练场地等权、场地内中心化的FPCA；90%解释方差目标、最多8维；target截距仅来自已测剖面；系数RBF核岭，长度为已测位置对距离中位数、ridge=.1 |
| 功能型线性空间趋势 | functional_fpca_linear | 同一FPCA，标准化xy的线性岭回归系数，ridge=1 |
| 全场图调和延拓 | graph_harmonic | 无标签计划位置4近邻对称图＋几何MST，水平高斯权重，尺度为边长中位数，平均水平加权度归一；相邻深度权重.15，已测整根作Dirichlet边界 |
| 图上边界保留重建 | graph_huber | 同图，pseudo-Huber边差，delta=.35 log(qc)，IRLS固定最多40轮；如未满足收敛条件，保留标记，不为追分追加迭代 |
| 绝对阻力剖面配准 | registered_profile_log | 最近3根已测剖面，配对距离medoid参考；单调配准位移≤2格(.5m)、局部厚度比例.5–1.5、固定端点，几何加权幅度与映射后逆映射 |
| 标准化形状配准 | registered_profile_shape | 同上，匹配标准化形状，减少幅度差对层界配准的影响 |
| 条件神经过程 | cnp_profile | 非Transformer、非残差的query-relative DeepSets；完整24点剖面编码，64维MLP、mean+max池化、深度条件解码，仅点预测；源v0.4轨迹按场地轮转，MAE，AdamW lr1e-3／wd1e-4，最多2000步、每100验证、至少400后patience4早停，seed20261014 |

FPCA只从对应fold的train_sites估计基；CNP只在source train梯度训练，source validation选权重。图模型显式获得完整计划位置的**无标签几何**，这些几何也是任务允许所有方法使用的信息，不能传入未揭示qc。配准只比较已测剖面，不能先查看query形状再做对齐，也不把自动对齐位置称为真实地层标签。

这些是新结构方向的适配实现，不是相关论文的完整复现。图模型仍包含空间平滑思想，功能型模型仍包含常规空间回归，配准后的空间加权仍使用距离；新机制分别在图信号边界条件、整剖面低秩表示、单调深度配准，而非既有参数的微调。
