## 已完成与已验证

- 12个模型均支持实际condition/predict推理。
- TabPFN、XGBoost、CNP、FPCA、GP所需工件由`artifacts/manifest.json`登记。
- 12模型×60状态共720项参考预测对照全部通过，低阻力标签变化0；最大点差约4.77e-7（CNP浮点运算）。
- 支持数据准备、组划分、固定状态验证，以及模型无关的两点选址、回放和成本计算。
- 21项当前测试通过。
- 结果通过`source_model_id`追溯原实验身份，当前成绩沿用冻结评价协议。
