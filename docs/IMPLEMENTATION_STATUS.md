更新日期：2026-10-17。当前阶段为 **adaptive_v1：AI自适应CPT补勘与经济效益评价**，使用已有v0.9.1权重并更新目标场地上下文。完整实现与实验结果已按[执行方案](../CPT_AI自适应补勘与经济效益_执行方案.md)推进；方法与冻结规则见[实验协议](ADAPTIVE_PROTOCOL.md)。

## 已完成的研究链路

- 五AI方法：GP、XGBoost残差、CNP、TabPFN joint、TabPFN＋graph；四项同代TabPFN消融，源权重更新及CNP训练合理性有诊断证据。
- 503条源剖面、495个计划位置、492个可用代表、31场地；24个深度单元合计11,808行。8回放场地×3预设种子，共24个完整组S0/C/A划分。
- 开发比较72个登记状态；评价比较63个登记状态（62个不同已知集、11个审计集）。所有方法在同一状态使用相同已测数据，按场地等权汇总。
- 按开发log-MAE冻结graph主模型，UDS权重0.5/0.3/0.2；停止条件含覆盖、稳定性、支持集留组误差和GP不确定性，至少9根、连续两轮。
- 完成48条开发完整轨迹、36条正式评价轨迹。最终展示72条三策略轨迹，保留未早停和未达研究质量目标的场地。
- 工程经济主情景α=1，涵盖直接费、现场工期、提前投用净收益和AI增量成本；含α、日收益及其他参数敏感性。模型计算耗时不作为本轮比较指标。

## 预测比较

4评价场地的注册状态均值：joint log-MAE **0.497141**，XGBoost **0.511805**（joint低约2.87%）；冻结graph为**0.502526**（低约1.81%）。GP厚度MAE最低，为**0.400318m**。graph提高部分低值召回，同时增加误报及厚度误差。完整五模型指标见[结果表](../results/adaptive_v1/model_comparison.csv)。

同代未微调joint略优于微调joint；原始残差路径的微调有小幅收益。结论取决于组合和评价场地，改进不能全部归因于微调或Transformer结构。
