# CPT v0.4：空间基线＋针对性残差训练

日期：2026-10-14。按用户要求直接在main提交，不创建开发分支。PR #1已在GitHub合并v0.2；v0.3诊断已直接合入main并推送，合并提交`b0e1ce7`。保留既有结果标签和历史版本。

## 本轮研究问题与边界

检验TabPFN能否从**与真实补勘几何一致的多情景源数据**学习IDW剩余误差，并在未参与源训练的验证场地上超过IDW／GP。空间基线本身保持不变；本轮首先实现IDW残差，GP继续作为强对照，不把方法名称写成已实施GP残差。

所有数据、勘察组划分、24深度单元、2–8m、1MPa、原点与风险评价沿用已冻结版本。学习率、候选和门槛在训练前冻结。现有外层结果已经被查看，本轮仍属于探索性研究；不能把这次验证称为独立确认性证明。

## 轨迹对齐的数据

源train采用固定种子107/211/307/401/503/601/701/809；源validation采用907/1009。每个源场地/种子先按完整near-group留出约20%查询位置，其余作行动池；随机第一点＋farthest初始5根，之后按相同maximin与批次间距条件逐次加入两根，形成5/7/9/11/13支持集。

小源场地只保留能够留下完整查询组的预算，不伪造13根；缺失/跳过原因明确记录。全部选择只看几何、ID与数量，不看qc或结果优劣。source train/validation场地名单取原fold，禁止生成test训练情景。

## 残差任务及训练

每个support行的标签为真实log(qc)减去整位置及同坐标留一IDW；query标签为真实log(qc)减去仅当前support算出的IDW。输入保持已验证24特征，避免同时更换表示导致无法解释结果。query真值只进入源训练loss和验证评价。

从相同官方TabPFN v2预训练权重独立训练两个候选：

- `crps`：原生残差分布CRPS＋MSE。
- `task`：上述损失＋0.5倍物理事件qc<1MPa的Brier损失。

**每个query残差空间中的事件阈值是−IDW_query，而不是统一的0。** 它必须继续经过support残差标准化与官方目标变换；推断时按正确的仿射CDF重建物理阻力分布。缩小残差不自动提供校准区间，必须报告实测覆盖。

每场地等次数轮转，场地内固定seed打散episode/完整query块。每候选每折最多600次成功更新，学习率1e-5，每100步验证，至少200步后允许按patience3早停。每批≤512行，保持整根CPT。明确记录episode和query-block覆盖率；600次更新不等于遍历全部数据，不以最终覆盖率代替最佳checkpoint覆盖率。

两候选均按源validation场地等权的`log-MAE + 0.5×物理原生Brier`选最佳checkpoint。最佳权重和训练终点分别记录。沿用已验证AMP恢复，失败更新不推进曝光计数。

## 实验比较与门槛

独立于源episode验证，回放比较复用v0.2相同60预算状态（3fold×2site×2seed×5budget），不改变已测点或评价位置。每种训练候选评估alpha=.25/.5/1原生残差，以及alpha=.25/.5点阈值保护，共10个新模型ID。

训练收益必须与**同alpha、同保护方式的v0.3未微调残差**比较。同时保留IDW、GP、独立XGB24及v0.2直接TabPFN作为参考，不能只选择容易超过的对手。风险采用相同留勘察组校准，原点标签与概率风险标签分别报告。

实施中追加一个更强的公平对照：在完全相同v0.4源轨迹上重新训练XGBoost IDW残差，复用既有深度4、学习率.05、最多500树、验证早停30和alpha护栏，CPU线程限制为2。这样可以区分新训练情景带来的收益与Transformer本身的作用。此对照不改变GPU候选或原门槛；所有FT候选额外与它配对比较，不因它更强而省略。对照模型ID为`xgb_residual_matched`。

另独立报告具有完整原生概率的模型在固定概率阈值.2下，原生与OOF校准概率的Brier、Recall、FPR差异。它仅用于区分模型与后处理的影响，不改变晋级门槛；点模型的原生概率缺失明确标记，不能把部分场地平均当成全体。

晋级沿用主要log-MAE严格优于每折IDW／GP较强者，H_point≤基线+.05m，risk Recall≥基线−.02，risk FPR≤基线+.02。全局按不同验证场地去重后严格多数改善；失败折保留基线。完整矩阵未齐不能选择。未通过则冻结负结果，不改门槛、删场地或转用训练成绩宣称收益。外层测试不自动运行。
