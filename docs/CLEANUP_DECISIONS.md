# 方案取舍与清理记录

## 保留口径

- 基线4个：常数中位数、优化等价IDW、空间GP、同轨迹XGBoost残差。
- TabPFN 2个：FPCA＋训练残差的符号保护；图Huber＋训练残差的低值并集。前者连续/风险较均衡，后者保留更好的低值召回；不单凭最低MAE选择损伤识别的混合版本。
- 主方案3个：均衡工程快版、Haar厚度工程快版、高召回识别。识别选recall60而非保守localize：召回48.77%、厚度.5269m，代价是点误报9.14%，在当前研究取舍中保留为识别代表。
- 讨论3个：simplex单独几何插值（简单结构已经很强）；count_shrink（最小MAE但厚度及耗时不划算）；CNP（复杂神经过程在当前数据上未优于强基线）。

TabPFN残差本身、FPCA、形状配准、图Huber及整曲线算子仍是必要组件，但不再各自形成一组独立实验入口。其他主方案按**点预测结构**分类；它们当前共享的独立经验风险头仍含TabPFN／图依赖，不能为凑数量删除这些依赖。
